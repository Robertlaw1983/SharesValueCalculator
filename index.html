一、市盈率估值法（P/E）
📌 适用范围： 盈利稳定公司成熟行业银行/消费/医药
① 适用于持续盈利且盈利波动较小的公司，亏损公司 EPS 为负无法使用；② 周期性行业盈利波动大，P/E 易失真；③ 高增长初创公司不适用。
⚠️ 注意：行业平均 P/E 应取同行业、同规模可比公司均值，剔除亏损/异常样本；重资产行业宜结合 P/B 使用。
二、市净率估值法（P/B）
📌 适用范围： 重资产行业银行/地产/钢铁扭亏企业
① 适用于资产密集型行业（银行、地产、钢铁、煤炭、化工），资产负债表中固定资产占比高；② 盈利为负但净资产为正的周期性低谷公司、ST 扭亏股可勉强使用；③ 金融企业（银行/保险/券商）最为匹配，监管要求其净资产需满足资本充足率。
⚠️ 注意：轻资产行业（互联网、咨询、软件）净资产极少，P/B 严重失真；商誉过高的公司应使用剔除商誉后的净资产。
三、市销率估值法（P/S）
📌 适用范围： 尚未盈利高成长科技电商/SAAS
① 适用于营业收入稳定但尚未盈利的高成长公司（科创版、创业板、Pre-IPO 互联网），P/E 无法使用时的替代方案；② 电商、SaaS、云计算等"先抢市占率、后释放利润"的行业尤为匹配；③ 营收操纵难度高于利润，数据可信度较好。
⚠️ 注意：P/S 无法反映利润率差异，同样 10 亿营收，10% 净利润率和 1% 净利润率的公司估值差一个数量级，使用时必须对比同行业净利率水平。

二、CAPM 模型计算股本成本
📘 公式：
Kₑ = Rբ + β × (E(Rₘ) − Rբ)
Kₑ = 股本成本（必要报酬率）　Rբ = 无风险利率（10年期国债收益率）
β = 个股系统性风险系数　E(Rₘ) = 市场组合期望收益率（沪深300均值）
E(Rₘ) − Rբ = 市场风险溢价（MRP）
📌 输出用途：① 作为投资组合业绩评价的基准（Jensen α、Treynor Ratio 计算）；② 作为 WACC 中股权成本的计算依据；③ 项目投资决策中风险调整折现率输入。
三、WACC 加权平均资本成本
📘 公式：
WACC = Kₑ × E / (E+D) + K𝒹 × (1−T) × D / (E+D)
E = 股权市值（股价×总股本）　D = 有息负债总额（债务市值）
T = 企业所得税税率　Kₑ = 股本成本（来自 CAPM）　K𝒹 = 税前债务成本
📌 输出用途：WACC 是FCFF 折现模型的核心折现率，也用于 DCF 估值、EVA 计算、投资项目 NPV 折现。数据自动同步给下一模块的 FCFF 折现使用。

二、DDM 股价估值计算
📘 三种模式核心公式：
零增长：P₀ = D / r　｜　不变增长（Gordon）：P₀ = D₁ / (r − g) = D₀·(1+g) / (r − g)
多阶段可变增长：P₀ = ΣDₜ/(1+r)ᵗ + Pₙ/(1+r)ⁿ ，其中 Pₙ = Dₙ₊₁ / (r − g稳态)
NPV = 股价估值 − 当前买入价 （NPV > 0 值得投资）；IRR = 令 NPV = 0 时的内部收益率（IRR > 必要报酬率 则低估）
📌 适用范围： 零增长：优先股稳定派息公用事业（水电燃气）｜不变增长（Gordon）：银行消费白马电力｜多阶段可变增长：高成长后趋于成熟
⚠️ 共同前提：公司必须有稳定派息历史和清晰的分红政策；不派息、或盈余不分红搞扩张的公司（如大多数成长股、科创股）DDM 严重失效，应使用 FCFF 模型。

三、EBIT 息税前利润计算
📘 公式：
EBIT = 营业收入 − 营业成本 − 研发费用 − 销售(营业)费用 − 管理费用
说明：此为"简化自上而下法"，假设无其他经营损益；若财报有明确披露的 EBIT，以其为准。
四、FCFF 自由现金流各项目填列
📘 公式：
FCFF = EBIT·(1−T) + 折旧摊销 − 净营运资本增加 − 资本性投资支出 + 其他调整项
